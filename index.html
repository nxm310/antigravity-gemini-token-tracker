🍎 Comment sélectionner le dossier .gemini sur Mac

Par défaut sur macOS, les dossiers commençant par un point (comme .gemini) sont cachés par Apple dans la boîte de dialogue de sélection de fichiers.

Raccourci magique macOS : 1. Cliquez sur le bouton bleu « Sélectionner le dossier Antigravity ».
2. Dans la fenêtre Finder qui s'ouvre, appuyez simultanément sur les touches :
⌘ Cmd + ⇧ Shift + . (Point)
3. Le dossier caché .gemini apparaît alors dans votre dossier personnel (Maison / /Users/votre_nom) !
4. Ouvrez .gemini puis sélectionnez antigravity et validez.

💡 Alternative encore plus simple : Vous pouvez aussi ouvrir le Finder, appuyer sur Cmd+Shift+., et glisser-déposer directement le dossier antigravity n'importe où sur cette page web !
